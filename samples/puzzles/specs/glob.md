Create `puzzles/match.py` with `match(pattern: str, text: str) -> bool`, a full-string regex-lite matcher WITHOUT using the `re` or `fnmatch` modules. Supported: literal chars, `.` any char, postfix quantifiers `*` (0+), `+` (1+), `?` (0/1) applying to the preceding atom, `\` escapes the next char (so `\.` `\*` `\\` are literals), character classes `[abc]`, ranges `[a-z0-9]`, negation `[^...]`. A quantifier with no atom or a dangling `\` or unclosed `[` raises ValueError. Must run in polynomial time (no exponential backtracking: `match("a*"*20 + "b", "a"*40)` must return quickly) — use DP or NFA simulation. Tests in `tests/test_match.py`.
